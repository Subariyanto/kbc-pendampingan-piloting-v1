Admin Terbitkan Kode Aktivasi

Admin Pokjawas login → menu Kode Aktivasi → klik "Terbitkan Kode". Pilih tier (Pro/Basic/Trial), isi nama pengawas, lalu salin kode yang dihasilkan.

👤 Admin Pokjawas
📨

Kode Diserahkan ke Pengawas

Admin mengirim kode aktivasi ke pengawas madrasah via WhatsApp atau langsung. Pastikan nama pengawas sudah diisi saat penerbitan agar kode tercatat Aktif.

👤 Admin → Pengawas
🌐

Pengawas Buka Aplikasi

Buka link aplikasi di browser: subariyanto.github.io/kbc-pendampingan-piloting-v1. Bisa di HP maupun laptop. Halaman aktivasi muncul otomatis untuk pengguna baru.

👤 Pengawas
📝

Isi Form Aktivasi

Masukkan Nama (sesuai yang terdaftar di admin), Kode Aktivasi, dan buat Password (min. 4 karakter). Klik "Aktivasi & Masuk".

👤 Pengawas
✅

Sistem Validasi Kode

Aplikasi memverifikasi kode (HMAC-SHA256) dan mencocokkan dengan roster lisensi online. Jika valid → akun tersimpan di perangkat. Jika gagal → periksa nama/kode atau hubungi admin.

⚙️ Sistem
🚀

Login & Mulai Pakai

Setelah aktivasi sukses, login dengan Nama + Password. Dashboard tampil → mulai input data madrasah, refleksi, rencana kerja, kegiatan supervisi, dokumentasi eviden, hingga laporan.
